# ExcitedBookWorm

ExcitedBookWorm — Telegram-бот на Python та aiogram 3.x, який допомагає користувачам знаходити книги за ключовими словами, настроєм і жанром. Бот отримує повідомлення через Telegram polling.

## Створення `.env`

Створіть бота через [@BotFather](https://t.me/BotFather) і отримайте токен. У корені проєкту створіть локальний `.env` на основі прикладу:

```bash
cp .env.example .env
```

Відкрийте `.env` і замініть значення `BOT_TOKEN` на токен від BotFather:

```env
BOT_TOKEN=ваш_токен_від_BotFather
```

Не додавайте `.env` до Git і не публікуйте токен. Файл уже виключений через `.gitignore`.

## Локальний запуск

Потрібен Python 3.10 або новіший. Із кореня проєкту створіть віртуальне середовище, встановіть залежності та запустіть бота:

```bash
python3.12 -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
set -a
source .env
set +a
python -m app.main
```

Після запуску відкрийте бота в Telegram і надішліть йому одну з команд нижче. Зупиніть процес клавішами `Ctrl+C`.

## Запуск через Docker

Переконайтеся, що Docker Desktop запущений і `.env` містить дійсний `BOT_TOKEN`. З кореня проєкту виконайте:

```bash
docker compose up --build
```

Команда збере образ за `Dockerfile` і запустить бота. Логи відображатимуться в терміналі; зупинка — `Ctrl+C`. Для запуску у фоні скористайтеся `docker compose up --build -d`, а для зупинки — `docker compose down`.

### Hot reload

Docker Compose підключає локальну папку `app/` до контейнера. `watchfiles` стежить за Python-файлами та автоматично перезапускає бота після змін у коді. Для змін у `app/` збірка не потрібна. Якщо змінюються `requirements.txt` або `Dockerfile`, запустіть `docker compose up --build` повторно.

## Команди бота

- `/start` — вітає користувача.
- `/help` — повідомляє, що це книжковий бот, який допомагає знайти книгу за настроєм і вподобаннями.
- `/age` — повідомляє, що вікові обмеження відсутні.
- `/about` — описує підбір книг за ключовими словами (наприклад, ліс, таємниця, міфи), настроєм (сумний, веселий, загадковий, злий) і жанром (роман, детектив, психологія, історія).
