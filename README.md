# ai-exbookw-course
Project name: ExictedBookWorm


Main goal: Допомагати користувачам знаходити ідеальну книгу відповідно до їхнього настрою, інтересів та вподобань.


Age: 0-100.


Features: Підбір книг за бажаними ключовими словами (наприклад: ліс, таємниця, міфи), настроєм (сумний, веселий, загадковий, злий і т.д.) та жанром (роман, детектив, психологія, історія і т.д.).
