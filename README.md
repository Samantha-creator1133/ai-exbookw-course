# ExcitedBookWorm

Telegram-бот на aiogram 3.x для підбору книг за ключовими словами, настроєм і жанром.

## Команди бота

- `/start` — вітає користувача.
- `/help` — коротко пояснює, що бот допомагає знаходити книги.
- `/age` — повідомляє, що вікові обмеження відсутні.
- `/about` — описує підбір книг за ключовими словами (наприклад, ліс, таємниця, міфи), настроєм (сумний, веселий, загадковий, злий) і жанром (роман, детектив, психологія, історія).

## Запуск

1. Переконайтеся, що в корені проєкту є файл `.env` зі змінною `BOT_TOKEN`. Якщо його ще немає, скопіюйте `.env.example` у `.env` і впишіть токен, отриманий від [@BotFather](https://t.me/BotFather).
2. Запустіть Docker Compose:

```bash
docker compose up --build
```

Після першої збірки Docker Compose запустить бота й покаже його журнали в терміналі. Відкрийте бота в Telegram і надішліть `/start`. Зупиніть бота натисканням `Ctrl+C`.

## Автоматичне перезавантаження коду

Папка `app/` підключена до контейнера як bind mount. `watchfiles` стежить за змінами Python-файлів і автоматично перезапускає бота. Після редагування коду повторно виконувати `docker compose up --build` не потрібно. Якщо змінюються залежності в `requirements.txt` або Dockerfile, перебудуйте контейнер:

```bash
docker compose up --build
```

`.env` містить локальний токен і виключений із Git. Не публікуйте його.
